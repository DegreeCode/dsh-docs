# 웹 UI 사용

[English](index.md) | [中文](index.zh.md) | 한국어

[루트 README](../../../README.ko.md#실행)를 통해 웹 UI를 시작하면 명령이 해당 URL을 출력합니다. 이 가이드는 서버가 실행 중인 상태에서 시작합니다. `dsh` 프로세스는 명령을 실행한 디렉터리를 기본 파일시스템 위치로 사용하지만, 웹 UI를 처음 열면 워크스페이스를 추가하기 전까지 선택된 워크스페이스가 없습니다.

## 모델 구성

**설정 → 모델**을 열고 [DeepSeek API 키](https://platform.deepseek.com/)를 입력한 뒤 저장합니다. 서버를 다시 시작하지 않아도 모델 경로를 바로 사용할 수 있습니다.

[모델 구성 가이드](./providers.ko.md)에서는 다른 제공자와 사용자 지정 OpenAI 호환 엔드포인트를 다룹니다.

## 워크스페이스 선택

**워크스페이스 선택**을 클릭하고 `dsh`를 시작한 프로젝트 디렉터리를 추가한 뒤 선택합니다. 워크스페이스를 선택하기 전에는 세션 입력창을 사용할 수 없습니다.

## 작업 실행

세션을 시작하고 다음을 보냅니다:

> 이 저장소를 요약하고 주요 패키지가 무엇인지 알려 주세요.

에이전트는 워크스페이스 파일을 읽고 편집하고, 명령을 실행하고, 작업을 위임하고, 계획을 유지할 수 있습니다. 웹 UI는 현재 권한 정책에서 승인이 필요한 작업을 수행하기 전에 확인을 요청합니다.
