# 쿡북: 플러그인 기능 미리보기 추가

[English](adding-a-plugin-preview.md) | [中文](adding-a-plugin-preview.zh.md) | 한국어

기능 미리보기는 번들 상세 문서 맨 위의 선택적 삽화이며, **플러그인** 화면에서 그 번들의 페이지가 가장 먼저 보여 주는 긴 설명입니다. 공식 번들을 위해 삽화를 그릴 때 이 가이드를 따르세요. 상세 문서 자체는 [`meta.detail`](adding-a-package.ko.md#plugin-display-metadata)로 선언합니다.

## 1. 이미지가 도움이 되는지 판단

구체적인 결과 하나나 알아볼 수 있는 기능 하나를 보여 주세요. 설명만으로 충분하면 이미지를 생략합니다. 즉 이미지는 필수가 아닙니다. 필수 안내는 문서 텍스트나 삽화 밖의 구성에 남깁니다.

## 2. 고정 크기 SVG 하나 그리기

| 항목 | 요구 사항 |
|---|---|
| 개수 | 번들당 기능 이미지는 0개 또는 1개입니다. 영어 파일과 중국어 파일은 그 이미지의 대안이며 갤러리나 캐러셀이 아닙니다. |
| 형식 | SVG: `width="640" height="300" viewBox="0 0 640 300"`(32:15). |
| 언어 | 영어 파일과 중국어 파일을 모두 제공합니다. 제목, 주석, 예제 콘텐츠는 번역하고 공식 브랜드 자산과 이름은 유지합니다. |
| 구성 | 주요 예제 하나, 선택적으로 근접 컷 하나를 둡니다. 중요한 콘텐츠는 캔버스 가장자리에서 약 32 단위 안쪽에 둡니다. 실제 페이지 크기에서 텍스트를 검토하세요. |
| 타이포그래피 | 적절한 글꼴로 글자를 패스로 외곽선화합니다. 기능과 인접 UI에 맞추고, 브라우저 글꼴 대체에 의존하지 마세요. |
| 테마 | 라이트 테마와 다크 테마를 비교합니다. 삽화 하나가 둘 다를 담당하므로, 어두운 배경에서 사라지는 반투명 어두운 텍스트를 피하세요. |

SVG는 자체 완결적입니다. 글꼴, 원격 리소스, 스크립트, 핸들러, 애니메이션, 스타일시트, `text`, `foreignObject`를 넣지 않습니다. `image` 요소는 변경하지 않은 공식 PNG/JPEG/WebP 브랜드 자산을 base64 데이터 URL로 포함할 수 있습니다. 작은 플러그인 아이콘은 기하 도형만 사용합니다. 페이지는 SVG를 `<img>`로 렌더링합니다. 각 파일을 작게 유지하세요. 호스트는 플러그인 관리자의 `detailImageMaxBytes`(기본 5 MiB)를 넘는 이미지를 거부합니다.

## 3. 상세 문서 맨 위에 두기

번들 패키지의 `docs/preview.svg`와 `docs/preview.zh.svg`로 저장하고, `docs/DETAIL.md`와 `docs/DETAIL.zh.md` 옆에 두며, 각 문서의 첫 줄을 이미지로 만듭니다:

```markdown
![Example feature preview](preview.svg)
```

중국어 문서는 중국어 대체 텍스트와 함께 `preview.zh.svg`를 참조합니다. [배지 스킬](../../packages/experimental/badge-skill-bundle/docs/DETAIL.md)과 [음성 입력](../../packages/experimental/voice-input-bundle/docs/DETAIL.md) 문서를 예로 사용하세요. 음성 전사는 녹음 결과가 아니라 설명용 예제 콘텐츠입니다.

## 4. 페이지 동작

| 항목 | 현재 동작 |
|---|---|
| 위치 | 상세 문서의 첫 부분이며, 상세 문서는 번들 페이지에서 설명과 상태 알림 아래에 오는 첫 섹션입니다. |
| 표시 | 상세 문서는 이미지를 자신의 너비를 넘지 않게, 높이가 제한된 스크롤 영역 안에서 렌더링합니다. |
| 언어 | UI 언어에 해당하는 문서가 자신의 파일을 참조합니다. |
| 가용성 | 활성화 전에도 보입니다. 목록과 컴포넌트 행은 작은 아이콘을 유지합니다. |

## 5. 검증과 리뷰

`scripts/plugin-preview-assets.spec.ts`는 번들의 `docs` 디렉터리에 있는 모든 미리보기 쌍을 검사합니다. 즉 고정 캔버스, 스크립트·스타일시트·텍스트 요소·외부 참조의 부재, 쌍당 1 MiB 제한, 서로 다른 영어 파일과 중국어 파일입니다. 그런 다음 활성화 전에 실제 플러그인 상세를 영어와 중국어로 열어 이미지 로딩, 배치, 라이트/다크 가독성, 390 px에서 가로 넘침이 없는지 확인하세요. 시각적 품질과 두 언어의 동등한 의미는 리뷰가 소유합니다. PR 증빙에는 [record-browser-gif](../../.agents/skills/record-browser-gif/SKILL.md)를 따르고, 최종 클린 커밋에서 녹화하며 시연한 흐름을 정확히 표기하세요.
