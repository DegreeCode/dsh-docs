# 포스트모템

[English](README.md) | [中文](README.zh.md) | 한국어

인시던트 기록입니다. 버그가 있어서는 안 되는 곳(실제 사용자, 머지된 PR, 릴리스)에 도달했고, 흥미로운 부분은 한 줄짜리 수정이 아니라 *우리 프로세스가 왜 그것을 통과시켰는가*입니다.

포스트모템은 [Agent Note](../../.agents/notes/README.md)가 **아닙니다**(Agent Note는 의도된 설계 결정과 기각된 대안을 기록하거나 향후 작업을 제안합니다). 포스트모템은 실패에 대한 회고 기록입니다. 무엇이 깨졌는지, 그 메커니즘, 왜 모든 안전망이 놓쳤는지, 그리고 같은 부류의 버그가 다음에 크게 실패하도록 추가한 구체적 가드레일입니다.

버그가 **미묘**하고(메커니즘이 자명하지 않아 꼼꼼한 엔지니어도 힘들게 다시 도출해야 합니다), **시스템적**이며(빠져나간 이유가 일회성 오타가 아니라 테스트/도구/관례의 빈틈입니다), **재발견 비용이 큰**(실제 디버깅 시간을 들였고 다시 들일) 경우에 작성합니다. 포스트모템이 촉발한 가드레일(테스트, AGENTS.md 규칙, ADR)을 연결하세요.

모든 포스트모템은 **요약(Executive summary)**으로 시작합니다. 바쁜 독자가 30초에 소화할 수 있는 짧은 문단 하나로, 무엇이 깨졌는지, 근본 원인을 쉬운 말로, 왜 빠져나갔는지, 그리고 남는 교훈을 담고, 그 뒤에 상세한 Summary / Timeline / Root cause / Guardrails 섹션이 이어집니다.
